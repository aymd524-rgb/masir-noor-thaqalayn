# راه‌اندازی متن کامل مصحف

نمایشگر مصحف در مسیر `/quran/mushaf` از API عمومی AlQuran Cloud استفاده می‌کند و متن صفحه‌ها را برای ۶۰۴ صفحه قرآن کریم به رسم‌الخط عثمانی دریافت می‌کند.

## منبع پیش‌فرض رایگان

- API: `https://api.alquran.cloud/v1/page/{page}/quran-uthmani`
- بدون حساب کاربری، API key یا کلید محرمانه
- متن صفحه و مرزبندی آیات از سرویس دریافت می‌شود.
- متن عربی عیناً از منبع نگهداری می‌شود و منبع در برنامه ذکر شده است.
- برنامه صفحه‌ها را در حالت روانخوانی نشان می‌دهد؛ چون این API شماره سطرهای دقیق مصحف ۱۵ سطری را ارائه نمی‌کند، چینش سطرها الزاماً مانند صفحه چاپی نیست.
- پاسخ صفحه در React Query نگهداری می‌شود و برای کاهش درخواست‌ها از cache سرویس نیز استفاده می‌شود. از درخواست‌های پشت‌سرهم و غیرضروری خودداری کنید.

شرایط متن: AlQuran Cloud اعلام کرده متن قرآن را می‌توان آزادانه نمایش و ذخیره کرد، به شرط حفظ متن و ذکر منبع. شرایط و محدودیت نرخ درخواست را در [Terms & Conditions](https://alquran.cloud/terms-and-conditions) بررسی کنید.

## گزینه دقیق‌تر: خط‌بندی ۱۵ سطری

برای حفظ شماره سطرهای منبع، کد اختیاری Quran Foundation Content API نیز آماده شده است:

`supabase/functions/mushaf-page/index.ts`

این روش نیاز به برنامه Backend/server، دسترسی Production و مجوز Content API دارد. محیط Pre-live فقط سوره‌های حمد و بقره را برای آزمایش ارائه می‌کند. پس از تأیید دسترسی، در Supabase Dashboard بخش **Edge Functions → Secrets** این مقادیر را تنظیم کنید:

- `QF_CLIENT_ID`
- `QF_CLIENT_SECRET` (فقط در Secrets؛ هرگز در GitHub، فایل VITE_ یا مرورگر قرار نگیرد)
- `QF_ENV=production`
- `QF_SCOPE=content.quran.read` برای مجوزهای جدید؛ اگر credential شما scope قدیمی `content` دارد، همان را قرار دهید.

سپس تابع `mushaf-page` را منتشر کنید و در تنظیمات build مقدار `VITE_MUSHAF_SOURCE=quran-foundation-edge` را انتخاب کنید. تنظیم `verify_jwt=false` فقط برای این تابع خواندنیِ عمومی است؛ تابع تنها صفحه قرآن را می‌خواند و عملیات نوشتن یا داده شخصی ندارد.

در پروژه Supabase فعلی هنوز Edge Function منتشر نشده است. **برای استفاده از منبع رایگان پیش‌فرض AlQuran Cloud نیازی به انتشار این تابع یا تنظیم Secrets نیست.**

## آزمون دستی

1. صفحه ۱ را باز کنید و سوره حمد را بررسی کنید.
2. صفحه ۲ و یک صفحه میانی مانند ۲۵۵ را باز کنید.
3. صفحه ۶۰۴ را باز کنید.
4. شماره آیه، نام سوره، انتخاب جزء و رفتن مستقیم به شماره صفحه را بررسی کنید.

این آزمون‌ها باید پس از انتشار نسخه جدید برنامه در مرورگر انجام شوند؛ تغییر کد در شاخه Git به‌تنهایی نسخه زنده را تغییر نمی‌دهد.
