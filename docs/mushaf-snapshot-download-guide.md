# دریافت و بررسی مصحف ۱۵ خطی

اسکریپت دریافت snapshot در `scripts/fetch-mushaf-snapshot.ts` دادهٔ متنی و شمارهٔ خطوط را از Quran.com API می‌گیرد و بین دو شناسهٔ مصحف مقایسه می‌کند.

## دستورها

- دریافت صفحات پیش‌فرض ۱ و ۲: `bun run mushaf:fetch`
- دریافت نمونهٔ صفحات ۱، ۲، ۵۰ و ۶۰۴: `bun run mushaf:fetch:sample`
- دریافت همهٔ صفحات: `bun run mushaf:fetch:all`
- دریافت صفحات مشخص: `bun scripts/fetch-mushaf-snapshot.ts --pages=1,2,50,604`

## نکات مهم

1. این دستورها نیاز به Bun و دسترسی اینترنت دارند.
2. `--all` دادهٔ ۶۰۴ صفحه را به‌صورت کامل درخواست می‌کند؛ ممکن است زمان‌بر باشد یا با محدودیت API روبه‌رو شود.
3. اجرای موفق اسکریپت فقط بررسی ماشینی منبع و خطوط را نشان می‌دهد؛ تطبیق بصری با نسخهٔ چاپی مرجع و تأیید مجوز استفاده همچنان لازم است.
4. قبل از جایگزینی snapshot فعلی، فایل را در یک شاخهٔ جدا بررسی کنید و تست‌ها را اجرا کنید: `bun run test` و `bun run build`.
5. اگر دریافت متوقف شد، خروجی ناقص را به‌عنوان قرآن کامل منتشر نکنید.

## وضعیت فعلی مخزن

فایل snapshot فعلی تنها نمونهٔ صفحات اولیه است. این راهنما به معنی دریافت یا تکمیل ۶۰۴ صفحه نیست.


## اجرای workflow دستی در GitHub

برای اجرای دریافت واقعی از محیط GitHub Actions:

1. صفحهٔ workflow را باز کنید:
   https://github.com/aymd524-rgb/masir-noor-thaqalayn/actions/workflows/mushaf-snapshot-manual.yml
2. اگر دکمهٔ **Run workflow** دیده نمی‌شود، شاخهٔ `integration/certificates-otp-2026-11-27` را از فهرست شاخه‌ها انتخاب کنید.
3. ابتدا `full_mushaf=false` و `pages=1,2,50,604` را اجرا کنید.
4. فقط پس از موفقیت job، از بخش **Artifacts** فایل snapshot نمونه را دریافت و بررسی کنید.
5. پس از تأیید نمونه‌ها، اجرای جداگانه با `full_mushaf=true` می‌تواند همهٔ ۶۰۴ صفحه را دریافت کند. این کار داده را به برنامه وصل یا منتشر نمی‌کند.

## بررسی artifact قبل از ادغام

- تأیید کنید حالت کامل دقیقاً ۶۰۴ صفحه دارد.
- بررسی کنید صفحات ۱، ۲، ۵۰ و ۶۰۴ بدون خطا و با خطوط معتبر هستند.
- اختلاف متن/خط، صفحهٔ خالی یا مسئلهٔ مجوز باید مانع ادغام شود.
- artifact موقت است و پس از ۷ روز منقضی می‌شود؛ نتایج را پیش از انقضا ثبت کنید.
- هرگز کلید API یا secret را در artifact، کد فرانت‌اند، issue یا چت قرار ندهید.
